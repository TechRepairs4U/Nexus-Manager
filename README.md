# Nexus Manager

[Download Nexus Manager](https://github.com/TechRepairs4U/Nexus-Manager/releases/tag/v0.1.2)

This repository hosts Nexus Manager releases and update downloads.
Choose the NRO, standalone NSP, or ZIP from the release page.

D1/D2 require a one-time manual installation of D3. After that, use
**Help & options → Check for Manager updates**. The HOME edition downloads
an NSP for separate installation; it does not install itself.

D3 is a development release. Follow the included instructions and keep backups.
Firmware and personal configurations are not included or changed.
